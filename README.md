# Python Basics Practice Project

This project contains beginner-level Python programs based on basic programming practice.

## Topics Covered

1. Printing messages with `print()`
2. Quotes, calculations, and Python syntax
3. Variables
4. Data types: `int`, `float`, and `str`
5. Sequence of instructions

## Files

- `01_print_messages.py` - Basic print statements
- `02_quotes_and_calculations.py` - Strings vs calculations and syntax
- `03_variables.py` - Creating and using variables
- `04_data_types.py` - Basic Python data types
- `05_sequence.py` - Sequential instructions

## How to Run

Make sure Python 3 is installed.

Example:

```bash
python 01_print_messages.py
```

You can run each `.py` file separately.
